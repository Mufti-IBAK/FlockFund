## 1. Executive Summary

This document outlines the technical requirements for converting the FlockFund platform from its original investment model to a **Shariah-compliant Mudarabah Al-Muqayyada (Restricted Mudarabah)** structure.

### Key Changes Summary

| Area | Original Model | New Mudarabah Model |
|------|----------------|---------------------|
| **Reserve Fund** | 8% of FlockFund profits set aside | **REMOVED** — not permitted in Mudarabah |
| **Profit Distribution** | 70% Investor / 30% FlockFund | **Capital returned first**, then 70% FlockFund / 30% Investor of **net profit** |
| **Loss Liability** | Shared via reserve fund | **100% borne by investor** (unless FlockFund negligence proven) |
| **Contract Requirement** | Standard Terms | **Formal Mudarabah Agreement** with specific clauses |
| **Cost Recovery** | Included in cost per bird | **Itemized and transparent** — deducted before profit calculation |

## 2. Mudarabah Al-Muqayyada — Foundational Principles

### 2.1 Definition

Mudarabah is a form of partnership where one party provides the capital (**Rabb-ul-Maal** — the investor) while the other party provides expertise and management (**Mudarib** — FlockFund). The profit is shared according to a pre-agreed ratio, while financial loss is borne solely by the capital provider, provided the Mudarib has not been negligent .

### 2.2 Al-Muqayyada (Restricted) Specification

This is a **Restricted Mudarabah (Al-Mudarabah Al-Muqayyada)** , meaning the Rabb-ul-Maal (investor) gives specific instructions regarding the investment of funds — in our case, **exclusively for broiler chicken farming** . The Mudarib (FlockFund) must adhere to these restrictions and cannot divert funds to other activities.

### 2.3 Core Rules Enforced by Shariah

| Rule | Description | Source |
|------|-------------|--------|
| **Profit Share Must Be Pre-Agreed** | The profit-sharing ratio must be determined at contract inception (e.g., 70/30). |  |
| **No Fixed Return** | Profit cannot be guaranteed as a fixed amount or percentage of capital — only as a share of actual profit. |  |
| **Loss Borne by Investor** | Financial loss (unless from negligence) is borne entirely by the capital provider. |  |
| **Mudarib Loses Effort** | The Mudarib loses time, effort, and resources — no compensation if no profit. |  |
| **Negligence Liability** | If loss is caused by Mudarib's negligence or breach, Mudarib must compensate. |  |
| **Capital Must Be Returned First** | Profit is only what exceeds the original capital. Losses are deducted from capital before profit calculation. |  |

### 3.1 Investment Lifecycle

```
┌─────────────────┐
│  Investor       │  Rabb-ul-Maal provides capital
│  (Rabb-ul-Maal) │  → System records investment
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  Contract       │  → Digital Mudarabah Agreement signed
│  Execution      │  → Profit ratio (70/30) acknowledged
└────────┬────────┘  → Investment restrictions acknowledged
         │
         ▼
┌─────────────────┐
│  Farm           │  → Flock purchased, raised, sold
│  Operations     │  → Daily keeper reports (biosecurity, health)
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  Flock Sale     │  → Revenue generated
│  Complete       │  → System calculates:
└────────┬────────┘    1. Return capital to investors
                     2. Deduct actual costs
                     3. Calculate net profit
                     4. Apply 70/30 split
         │
         ▼
┌─────────────────┐
│  Distribution   │  → Capital + profit share → Investor
│                 │  → FlockFund profit share → Platform
└─────────────────┘
```

```sql
    investor_profit_share DECIMAL, -- net_profit * 30%

);

-- 5. INCIDENT_REPORTS table (NEW) — for negligence tracking
CREATE TABLE incident_reports (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    flock_id UUID REFERENCES flocks(id),
    incident_date DATE,
    description TEXT,
    cause TEXT, -- 'disease', 'natural_disaster', 'negligence', 'mismanagement'
    investigation_notes TEXT,
    findings TEXT,
    negligence_found BOOLEAN DEFAULT FALSE,
    reported_by UUID REFERENCES profiles(id),
    resolved_at TIMESTAMP,
    -- If negligence found, loss becomes Mudarib liability
    compensation_required DECIMAL DEFAULT 0
);
```

### 3.3 Profit Calculation Logic — Pseudo-code

```javascript
function calculateFlockProfit(flockId) {
    // 1. Get all investments for this flock
    const investments = db.investments.find({ flock_id: flockId });
    const totalCapital = sum(investments.map(i => i.capital_amount));
    
    // 2. Get total revenue from bird sales
    const totalRevenue = db.sales.sum({ flock_id: flockId });
    
    // 3. Get verified costs (tax, stamp duty, operational)
    // IMPORTANT: Costs must be actual, reasonable, and verifiable
    const totalCosts = db.flock_costs.sum({ flock_id: flockId, verified: true });
    
    // 4. Calculate capital + costs
    const capitalPlusCosts = totalCapital + totalCosts;
    
    // 5. If revenue < capitalPlusCosts → LOSS scenario
    if (totalRevenue < capitalPlusCosts) {
        // Check for negligence
        const negligenceFound = db.incident_reports.findOne({ 
            flock_id: flockId, 
            negligence_found: true 
        });
        
        if (negligenceFound) {
            // FlockFund must compensate investors fully
            triggerCompensation(flockId, totalCapital);
            return {
                status: 'LOSS_DUE_TO_NEGLIGENCE',
                action: 'FlockFund liable for full capital return'
            };
        } else {
            // Normal loss — investors bear proportionally
            const recoveryRate = totalRevenue / capitalPlusCosts;
            distributeLoss(flockId, recoveryRate);
            return {
                status: 'LOSS',
                message: 'Investors receive proportional capital back',
                recovery_rate: recoveryRate
            };
        }
    }
    
    // 6. PROFIT scenario
    // Revenue exceeds capital + costs
    const netProfit = totalRevenue - capitalPlusCosts;
    
    // Apply 60/40 split
    const investorProfit = netProfit * 0.3;
    const mudaribProfit = netProfit * 0.7;
    
    // Each investor gets:
    // - Their full capital back
    // - Their share of investorProfit (proportional to their capital)
    distributeProfits(flockId, totalCapital, investorProfit);
    
    return {
        status: 'PROFIT',
        net_profit: netProfit,
        investor_pool: investorProfit,
        mudarib_share: mudaribProfit
    };
}
```

## 4. Critical Shariah Rules — Implementation Requirements

### 4.1 No Guarantee of Profit or Principal

**Rule:** The Mudarabah agreement cannot promise a fixed return or guarantee the capital .

**Implementation:**
- Remove any language suggesting "guaranteed returns" from UI
- Add prominent disclaimer: "Investment returns are based on actual farm performance. Capital may be at risk."
- In calculators, show **projections** not guarantees
- All historical returns must be labeled as "past performance"

### 4.2 Profit Sharing Ratio Must Be Pre-Agreed

**Rule:** The ratio (70/30) must be agreed before the contract begins .

**Implementation:**
- During checkout, display profit-sharing ratio prominently
- Require explicit acknowledgment before investment
- Store agreed ratio in `investments` table
- Ratio cannot change mid-cycle

### 4.3 Loss Liability — Investor Bears Financial Loss

**Rule:** Financial loss from normal business operations is borne by the capital provider .

**Implementation:**
- Remove Reserve Fund logic completely
- Update risk disclosures
- In loss scenarios, system automatically calculates proportional capital return
- No recovery from FlockFund unless negligence proven

### 4.4 Negligence Liability — FlockFund Bears Loss

**Rule:** If loss is caused by Mudarib's negligence or breach, Mudarib is liable .

**Implementation:**

**Definition of Negligence (from Islamic scholarship)** :
- Failure to follow agreed-upon biosecurity protocols
- Ignoring veterinary advice
- Misappropriation of funds
- Investing in prohibited activities
- Gross mismanagement

**System Requirements:**
- `incident_reports` table to document any adverse events
- Farm Manager must investigate and document causes
- If negligence found, flag `negligence_found = true`
- Trigger compensation workflow (FlockFund must return capital)

### 4.5 Capital Must Be Returned Before Profit

**Rule:** Profit is what exceeds the capital .

**Implementation:**
- In profit calculation, ensure `totalCapital` is subtracted first
- UI should show breakdown:
  - Your Capital: ₦X
  - Farm Costs: ₦Y
  - Net Profit: ₦Z
  - Your 30% Profit Share: ₦Z × 0.3
  - **Total to You: Capital + Profit Share**

## 6. Legal & Compliance Requirements

### 6.1 Mudarabah Agreement — Required Clauses

Based on Shariah requirements , the agreement must include:

| Clause | Content |
|--------|---------|
| **Parties** | Full names and identification of Rabb-ul-Maal (investor) and Mudarib (FlockFund) |
| **Capital** | Amount provided, currency, and delivery method |
| **Business Scope** | Restricted to broiler chicken farming only (Al-Muqayyada)  |
| **Profit Ratio** | 60% to Mudarib, 40% to Rabb-ul-Maal — agreed upfront  |
| **Loss Provision** | Financial loss borne by Rabb-ul-Maal unless caused by Mudarib's negligence  |
| **Negligence Definition** | Clear definition of what constitutes negligence (failure to follow protocols, ignoring vet advice, etc.) |
| **Costs** | Which costs are deductible before profit calculation (must be actual and reasonable) |
| **Duration** | Expected duration of the Mudarabah (flock cycle) |
| **Termination** | How the contract can be terminated early (if applicable) |
| **Dispute Resolution** | Mechanism for resolving disputes (arbitration recommended) |

## 7. Risk Management Under New Model

### 7.1 Risk Allocation Summary

| Risk Type | Who Bears | Notes |
|-----------|-----------|-------|
| **Disease outbreak (no negligence)** | Investor | Financial loss borne by capital provider  |
| **Market price drop** | Investor | Part of normal business risk |
| **Natural disaster** | Investor | Force majeure — investor bears loss |
| **Negligence/mismanagement** | FlockFund | Must compensate investors  |
| **Operational inefficiency** | Shared | Lower profits affect both parties |

### 7.2 Protection for Investors (Non-Financial)

While investors bear financial loss, they have important protections under Shariah :

1. **Right to transparency** — All farm activities visible in real-time
2. **Right to restrict investment** — Al-Muqayyada ensures funds used only for poultry
3. **Right to hold Mudarib accountable** — If negligence proven, Mudarib liable
4. **Right to profit share** — 40% of any net profit
5. **Right to capital priority** — Capital returned before profit calculated 

### 7.3 Negligence Investigation Workflow

```mermaid

    A[Incident Reported by Keeper] --> B[Farm Manager Investigates]
```
